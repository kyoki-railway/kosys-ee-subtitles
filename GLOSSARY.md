## Railway Terms / 鉄道用語

| Japanese | English | Notes |
|---|---|---|
| CTC（列車集中制御装置） | Centralized Traffic Control (CTC) | System controlling signals and switches centrally |
| 閉塞 | Block (signaling) | System ensuring only one train per section |
| 自動閉塞 | Automatic block signaling | Normal signaling mode |
| 代用閉塞 | Substitute block signaling | Manual fallback when automatic system fails |
| 指導通信式 | Pilot communication system | Manual train control method |
| 防護無線 | Emergency radio | Radio system to halt all trains in the area |
| 非常発報 | Emergency broadcast | Activation of the emergency radio |
| 信号冒進 | Signal Passed At Danger (SPAD) | Train passing a red signal |
| 停止現示 | Stop aspect / red signal | Signal displaying "stop" |
| 出発信号機 | Departure signal | Signal authorizing a train to leave a station |
| 場内信号機 | Home signal | Signal authorizing entry into a station |
| 在線位置表示 | Train position display | Shows where trains are located on the line |
| 運転整理 | Train traffic management / rescheduling | Adjusting train operations during disruption |
| 輸送指令 | Transport Command / Dispatch | Central operations command |
| 輸送障害 | Service disruption | Disruption to transport services |
| 回送列車 | Deadhead train | Non-revenue train movement |
| デッドロック | Deadlock | Used for both trains (gridlock) and computing |
| 鉄道事故等報告規則 | Railway Accident Reporting Rules | Legal reporting requirements |
| 運転安全規範 | Operational Safety Code | Safety principles for railway employees |
| 動力車操縦者運転免許 | Train driver's license | Per 戸籍法施行規則 official English translation |

## Catchphrases & Recurring Expressions / 決め台詞・定型表現

| Japanese | English | Context |
|---|---|---|
| モッタイナイ 直せばまだまだ走れます | "Mottainai — fix it and it'll run forever" | Kyōki Railway's (ironic) company motto |
| モッタイナイ その判断が 命取り | "Mottainai — that mindset will be your downfall" | Akane's retort to the motto |
| 定時は守るもの | "Quitting time is sacred" | Akane's personal motto |
| だってお金ないもん | "But we don't have any money" | CIO's catchphrase |
| 何も起こらなければいいんですけどね | "Let's just hope nothing happens..." | Recurring ironic foreshadowing |
| 起きました | "It happened." | Response to the above |
| 天上ノ瑕疵誘因（アルティメットバグトリガー） | Ultimate Bug Trigger | Mei's nickname |
| 黒炎纏いし棺の主《ローメンテナンサビリティコードマスター》 | Low-Maintainability Code Master | Lt. Commander's nickname. Furigana in SRT is ローメンテナンサビリティ (not アンメンテナンサブル) |

## Notable Puns & Cultural References / ダジャレ・文化的参照

| Japanese | Explanation | Suggested English rendering |
|---|---|---|
| どすこい / DoS攻撃 | Mei confuses "DoS attack" with "Dosukoi" (sumo chant) | Keep both terms visible: "DoS...koi?" |
| キク科 / 聞くか | Asteraceae plant family / "Are you asking me?" | "Why would you *aster* me that?" or similar |
| コスモスベルグでギャグも滑るグ | Cosmos Berg + 滑る (to slip / jokes bombing) | "At Cosmos Berg, even jokes fall flat-berg" |
| 精一杯 頑張りんご | がんばり (effort) + りんご (apple); Yamagata/Aomori reference | "We'll give it our apple — I mean, our all!" |
| 逆境に負けねでけろな | Yamagata dialect: "Don't lose to adversity" | "Don't let hard times get you down, y'hear?" |
| シカたありません | しかたありません (can't be helped) + シカ (deer) | "Nothing we can do — oh *deer*" |
| ノリツッコミの脆弱性 | Susceptibility to comedy routines (nori-tsukkomi) | "Tsukkomi vulnerability" |
| オハようございまスハフ | おはよう + スハフ (train car type) | "Good MOHAning, SuHaFu!" |
| オロオロネ | おろおろ (flustered) + オロネ (sleeping car type) | Train car name puns (convey mixing greetings with train designations) |
| 台本インジェクション | "Script injection" — characters inject commands into their own anime's script | Literal: "Script injection attack" |
